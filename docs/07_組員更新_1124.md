## 4. 三個會被問到的事實（建議都記一下）

1. **`Target = 1` ⟺ `class == "Lung Opacity"`**，永遠成立（6,012 張雙向吻合）。
   所以 `class` 的用途是細分「沒有框」那一群，不是標示肺炎。
2. **訓練集 77.47% 的影像沒有框**，而陰性影像只要畫了任何框該張就是 0 分。
   這是整個競賽策略的起點。
3. 常用數字：標註 **30,227 列 / 26,684 張影像 / 9,555 個框**，
   三類佔比 `No Lung Opacity / Not Normal` **44.30%** ＞ `Normal` 33.17% ＞ `Lung Opacity` 22.53%。
