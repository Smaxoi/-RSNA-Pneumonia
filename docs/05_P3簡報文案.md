## 1. 圖 1 — 類別分布

### 可以直接貼上簡報的結論

> **最大的類別不是「正常」，也不是「肺炎」，而是佔 44.3% 的「不正常但非肺炎」。**
> 這些片子有白影卻必須不畫框 —— 它們是誤判的主要來源。

### 第二句（這張圖右邊那格）

> **在有肺炎的影像裡，兩個框 (3,266) 比一個框 (2,614) 還多，
> 超過一半 (56.5%) 有兩個以上的框。** 肺炎常是雙側的，模型找到一個不能就停。

### 口頭補充

把它跟評分規則接起來，這頁的份量會完全不同：

> 「競賽規則是**陰性影像只要畫了任何框，該張直接 0 分**。
> 而我們剛看到，44.3% 的片子『不正常但不是肺炎』—— 它們有白影、長得像肺炎，
> 卻必須一個框都不畫。這 44.3% 就是這題最危險的地方。」

### 支撐數字

| | 張數 | 佔比 |
|---|---|---|
| No Lung Opacity / Not Normal | 11,821 | 44.3% |
| Normal | 8,851 | 33.2% |
| Lung Opacity | 6,012 | 22.5% |
| **沒有框（Target=0）** | **20,672** | **77.5%** |

## 2. 圖 2 — Bounding box 尺寸

### 可以直接貼上簡報的結論

> **病灶框平均佔整張影像的 7.4%，但範圍從 0.2% 到 35.4%，最大與最小相差 160 倍。**
> 這不是單一尺度的問題，需要能處理大小差異極大的目標。

### 第二句

> **長寬比中位數 0.69（高度約是寬度的 1.45 倍）**，框普遍高瘦，符合肺葉的形狀。

### 實作意涵（這句讓 P3 和 P4 接得起來）

> 「因為尺度跨度這麼大，我們**不打算把輸入影像縮太小**，
> 也對『統一縮小預測框』這種後處理保持保留 —— 它對小病灶的傷害會比大病灶嚴重。」

### 支撐數字

| | 中位數 | 平均 | 最小 | 最大 |
|---|---|---|---|---|
| 框寬 (px) | 217 | 218 | 40 | 528 |
| 框高 (px) | 298 | 329 | 45 | 942 |
| 面積佔比 | 6.2% | 7.4% | 0.22% | 35.4% |
| 長寬比 | 0.69 | 0.79 | 0.22 | 4.36 |

## 3. 圖 5 — 空間分布

**這張圖是三張裡最好看、也最好講的，建議放最大。**

### 可以直接貼上簡報的結論

> **框的中心形成左右兩個清楚的叢集，對應左右肺；垂直位置高度集中 ——
> 一半的框中心落在 y = 455~609 這 154 像素內，只佔影像高度的 15%。**
> 影像的四個角落幾乎不會出現病灶。

### 實作意涵

> 「這是很強的位置先驗。畫在影像邊緣的預測框幾乎一定是錯的，
> 這給了我們一個幾乎零成本的後處理篩選條件。」

### 支撐數字

- 框中心水平位置：平均 503，標準差 205（雙峰，左右肺）
- 框中心垂直位置：平均 531，標準差 115，四分位距 455~609
- 水平的分散程度是垂直的 **1.8 倍** —— 這就是「左右兩叢」的量化說法

## 4. 如果版面還有空間：一個很有說服力的發現

> **AP（躺著拍）的影像有 37.3% 是肺炎，PA（站著拍）只有 9.2%，相差四倍。**

AP 是臥床、重症或急診病人用移動式機器拍的；PA 是站得起來的門診病人。
**病情嚴重度本身就反映在拍攝方式上。**

這句話放在頁尾一行就夠，但它顯示我們不只是在數筆數 —— 我們看懂了資料背後的臨床情境。

> ⚠️ 講的時候要誠實：這是**關聯不是因果**，也不代表該把 ViewPosition 當特徵餵給模型
> （那等於讓模型去猜「這個病人病得多重」而不是「影像上有沒有病灶」）。
> 講成「這說明資料不是隨機抽樣的」會更站得住腳。

## 5. 一個數字絕對不要放上簡報

相關性那張圖裡有這一條：

```
框數  vs  肺炎Target   +0.933
```

**這是定義造成的假相關，不是發現。**
`Target` 的定義就是「這張影像有沒有框」，`框數` 是框的數量 ——
有框必然 Target=1，沒框必然 Target=0。它們相關是因為它們本來就是同一件事。
（沒有剛好等於 1.000 只是因為框數有 1、2、3 的差異。）

把它當成「我們發現框數和肺炎高度相關」講出來，**一定會被問倒**。

真要用只能這樣用：「這一條驗證了我們的標籤處理沒出錯。」

### 可以放的加分項

```
年齡最大值 = 155 歲
```

DICOM header 裡有不可能的數值。拿出來講一句「**我們檢查過 metadata，
發現年齡欄位有髒值，所以不會直接拿它當特徵**」，
比任何漂亮的圖都更能證明我們真的打開過資料。

## 7. 🔴 來源 URL（這頁的硬性要求）

老師的投影片用紅字強調**這一頁要附參考來源**。沒附就是確定扣分。

頁尾加一行，字可以小，但要有完整 URL：

```
資料來源：RSNA Pneumonia Detection Challenge (Kaggle, 2018)
https://www.kaggle.com/competitions/rsna-pneumonia-detection-challenge/data
分析方法參考：<你實際看過的那個 Kaggle Code notebook 的 URL>
```

第二行要**真的去競賽的 Code 分頁找一個你有看過的 EDA notebook**。
隨便掛一個沒看過的連結，被問到裡面有什麼會很難看。
