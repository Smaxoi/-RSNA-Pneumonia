# 環境建置指南

> 目標：讓每個人的電腦都能跑同一份程式、得到同一個結果。
> 照著做大約 20 分鐘（不含下載資料）。

---

## 0. 需求確認

| 項目 | 需求 | 備註 |
|---|---|---|
| OS | Windows 10/11、macOS、Linux 皆可 | 本文以 Windows 為主 |
| Python | 3.11（由 conda 建立） | 不要用系統內建的 Python |
| 硬碟 | 至少 **15 GB** | 資料 4 GB + PyTorch 3 GB + processed 2 GB |
| GPU | NVIDIA，**6 GB VRAM 以上**建議 | 沒 GPU 也能跑，但訓練很慢，建議改用 Colab |
| 網路 | 下載資料約 3.7 GB | 學校網路會快很多 |

**已驗證可用的配置**：Windows 11 + RTX 4060 Laptop (8 GB) + CUDA 12.6 + Python 3.11

---

## 1. 安裝 Miniforge（如果還沒有 conda）

下載：<https://github.com/conda-forge/miniforge/releases>
→ 選 `Miniforge3-Windows-x86_64.exe`，安裝時勾選「Add to PATH」。

驗證：開一個新的 PowerShell 視窗，輸入

```bash
conda --version
```

有印出版本號就成功。

---

## 2. 一鍵建立環境

在專案根目錄開 PowerShell：

```bash
powershell -ExecutionPolicy Bypass -File setup_env.ps1
```

這支腳本會做四件事：
1. 用 `environment.yml` 建立名為 `rsna` 的 conda 環境（Python 3.11）
2. 從 PyTorch 官方 index 安裝 **CUDA 12.6 版**的 torch / torchvision
3. 安裝 `requirements.txt` 裡的其餘套件
4. 跑 `src/check_env.py` 驗證

---

## 3. 手動安裝（腳本失敗時的備案）

## 4. Kaggle 認證（下載資料用）

> 📌 本專案安裝的是 Kaggle CLI **2.2.5**，認證方式已經改成 OAuth，
> **不再需要手動放 `kaggle.json`**。網路上大部分教學是舊的，以這裡為準。

### 步驟

```bash
conda activate rsna
```

```bash
kaggle auth login
```

會自動開瀏覽器要你授權，按下同意後憑證就快取在本機，之後都不用再弄。

⚠️ **接著一定要做這一步**：到
<https://www.kaggle.com/competitions/rsna-pneumonia-detection-challenge/rules>
按下 **I Understand and Accept**。沒接受規則，下載會直接回 **403 Forbidden**。

然後就能下載了：

```bash
python src/download_data.py
```

### 替代做法（OAuth 開不了瀏覽器時）

到 <https://www.kaggle.com/settings/api> 按 **Generate New Token**，然後擇一：

| 方式 | 做法 |
|---|---|
| 環境變數 | 設 `KAGGLE_API_TOKEN=<你的 token>` |
| token 檔 | 存成 `~/.kaggle/access_token`（Windows 是 `C:\Users\<帳號>\.kaggle\access_token`） |
| 舊格式 | `~/.kaggle/kaggle.json`，仍相容但不建議 |

🚨 **絕對不要把任何憑證檔上傳到 GitHub**（`.gitignore` 已經擋掉，但還是提醒一下）。

## 6. 常見問題

### Q1：`conda activate rsna` 沒反應 / 報錯

PowerShell 第一次用 conda 要初始化：

```bash
conda init powershell
```

然後**關掉視窗重開**。

---

### Q2：`torch.cuda.is_available()` 是 False

依序檢查：

1. 先確認驅動有抓到卡：
   ```bash
   nvidia-smi
   ```
2. 看裝到的是不是 CPU 版（版本號結尾沒有 `+cu` 就是 CPU 版）：
   ```bash
   python -c "import torch; print(torch.__version__, torch.version.cuda)"
   ```
3. 是 CPU 版的話，砍掉重裝：
   ```bash
   pip uninstall -y torch torchvision
   ```
   ```bash
   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
   ```
4. 驅動比較舊（`nvidia-smi` 顯示的 CUDA 版本 < 12.6）就改裝 cu121：
   ```bash
   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
   ```

---

### Q3：訓練時 `CUDA out of memory`

依這個順序調，改 `src/config.py`：

1. `BATCH_SIZE = 8` → `4` → `2`
2. `IMAGE_SIZE = 640` → `512`
3. `MODEL_NAME = "yolov8s.pt"` → `"yolov8n.pt"`
4. 關掉瀏覽器和其他吃 VRAM 的程式（`nvidia-smi` 可以看誰在佔用）

---

### Q4：`pydicom` 讀檔報 `NotImplementedError` 或缺 handler

本競賽的 DICOM 是未壓縮的，正常不會遇到。真的遇到就補裝解碼器：

```bash
pip install pylibjpeg pylibjpeg-libjpeg python-gdcm
```

---

### Q5：圖表上的中文變成空白方框 □□□

`src/eda.py` 已經設定微軟正黑體。如果你是 macOS / Linux，改 `eda.py` 開頭的字型清單，
或安裝 Noto 字型：

```bash
conda install -c conda-forge font-ttf-noto-sans-cjk
```

---

### Q6：`cv2` 匯入失敗（ImportError: DLL load failed）

```bash
pip uninstall -y opencv-python opencv-python-headless
```

```bash
pip install opencv-python
```

---

### Q7：沒有 GPU 怎麼辦

用 **Kaggle Notebook**（每週 30 小時免費 GPU，而且資料已經掛好不用下載）或 **Google Colab**。
把 `src/` 整包上傳，改 `config.RAW_DIR` 指到
`/kaggle/input/rsna-pneumonia-detection-challenge/` 就能直接跑。

## 8. 版本一致性

為了避免「在我電腦上可以跑」，環境裝好後請跑一次並把結果貼到群組：

```bash
python src/check_env.py
```

有人版本對不上時，用這個鎖定版本：

```bash
pip freeze > requirements-lock.txt
```
