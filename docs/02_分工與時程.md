## 5. 協作規則

### 程式
- **不要各自改同一個檔案**。要改共用的 `config.py` 先在群組講一聲。
- 新功能寫成 `src/` 底下的新檔案，不要把實驗程式塞進既有腳本。
- 實驗性質的東西放 `notebooks/`，命名用 `姓名_主題.ipynb`。

### 檔案
- `data/`、`models/`、`runs/` 都**不進 git**（`.gitignore` 已設定）。
- 訓練好的權重、EDA 圖表用雲端硬碟共享，不要塞進 repo。

### 實驗紀錄
每跑完一次訓練，在群組或共用文件記一行：

```
[日期] 模型=yolov8s imgsz=640 epochs=30 conf=0.35 shrink=0.90 -> val mAP=0.187
```

這樣簡報第 4 頁的比較表直接整理就有了。

## 6. 風險與備案

| 風險 | 機率 | 備案 |
|---|---|---|
| 有人 GPU 裝不起來 | 高 | 改用 Kaggle Notebook（免費 GPU 30 hr/週，資料已掛載） |
| 資料下載太慢 | 中 | 一人下載好後用隨身碟/雲端分享 `raw/` |
| 訓練時間不夠 | 中 | 降到 `yolov8n` + `imgsz=512` + 10 epoch，先求有數字 |
| mAP 太低不好看 | 中 | 說明「第一名也只有 0.25」，重點放在**分析與方法論**而非分數 |
| 簡報來不及統整 | 低 | D-2 就要有完整草稿，不要留到最後一天 |
