## 1. 我們在做什麼？（一句話版）

> **給一張胸部 X 光片，讓電腦自動框出「可能是肺炎」的位置。**

```
        輸入                          輸出
   ┌─────────────┐              ┌─────────────┐
   │             │              │   ┌───┐     │
   │   胸部      │   ──模型──►  │   │ ▓ │     │  ← 紅框 = 這裡疑似肺炎
   │   X 光片    │              │   └───┘ ┌──┐│
   │             │              │        │▓ ││
   └─────────────┘              └────────└──┘┘
    1024 x 1024                   框的座標 + 信心值
```

這是 2018 年北美放射學會（RSNA）在 Kaggle 辦的競賽，獎金三萬美金。
競賽已經結束了，但還開放 **Late Submission**，我們交上去一樣看得到分數。

**為什麼要做這個？**
肺炎在 X 光上長得像一塊「比較白、比較模糊的區域」。但肺積水、肺出血、肺塌陷、
肺癌……也都長這樣。連放射科醫師都要搭配病史才敢下診斷。
醫院希望有個 AI 先幫忙篩一輪，把可疑的片子排前面，讓醫師優先看。

## 2. 最容易搞錯的一點：這是「偵測」不是「分類」

這點一定要先講清楚，不然後面全都會想歪。

| | 分類（Classification） | **偵測（Detection）← 我們要做的** |
|---|---|---|
| 問題 | 「這張片子有沒有肺炎？」 | 「肺炎**在哪裡**？」 |
| 輸出 | 一個答案：有 / 沒有 | 一堆**方框的座標** |
| 像什麼 | 考是非題 | 考「請在圖上圈出答案」 |
| 常用模型 | ResNet、EfficientNet | **YOLO**、Faster R-CNN |

所以我們的模型輸出長這樣：

```
這張片子 → [(x=264, y=152, 寬=213, 高=379, 信心=0.87),
            (x=562, y=152, 寬=256, 高=453, 信心=0.81)]
```

兩個框，通常是左肺一個、右肺一個。

如果模型覺得沒肺炎，就**什麼框都不輸出**（空的）。
所以「有沒有肺炎」這件事，是靠「有沒有輸出框」來表達的 —— 偵測把分類也包進去了。

## 3. 資料長什麼樣？

### 三個檔案就講完了

**① 影像**：26,684 張訓練用的胸部 X 光，格式是 **DICOM**（`.dcm`），醫院專用格式。
每張都是 1024×1024 的灰階圖。用 `pydicom` 這個套件讀，兩行就打開了。

**② 標註 CSV**（`stage_2_train_labels.csv`）：

```
patientId                              x     y     width  height  Target
0004cfab-14fd-4e49-80ba-63a80b6bddd6   NaN   NaN   NaN    NaN     0      ← 沒肺炎，沒框
00436515-870c-4b36-a041-de91049b9ab4   264   152   213    379     1      ← 右肺的框
00436515-870c-4b36-a041-de91049b9ab4   562   152   256    453     1      ← 左肺的框
```

要注意三件事：
- **同一張片子可能有好幾列**（有幾個框就幾列）
- **沒肺炎的那列，座標全是空的**
- 座標是「**左上角 x, y + 寬 + 高**」，不是左上右下、也不是中心點

**③ 類別 CSV**（`stage_2_detailed_class_info.csv`）：每張片子屬於哪一類

| 類別 | 白話 | 要不要框 |
|---|---|---|
| `Normal` | 完全正常 | ❌ |
| `No Lung Opacity / Not Normal` | **不正常，但不是肺炎** | ❌ |
| `Lung Opacity` | 有肺炎陰影 | ✅ |

> 🔑 **第二類是這題的大魔王。**
> 它在影像上也有一塊白白的東西，但答案是「不要框」。
> 模型最常在這裡出錯 —— 看到白影就框下去，結果扣分。
> 這點放進簡報第 2 頁或第 3 頁，會顯得我們真的有讀懂資料。

## 4. 怎麼評分？（這段最值錢，請耐心看）

### 先懂 IoU

IoU = 兩個框「重疊的面積」÷「加起來的面積」。

```
   你畫的框          正確答案          IoU 高              IoU 低
   ┌─────┐          ┌─────┐          ┌──┬──┐           ┌───┐ ┌───┐
   │     │          │     │          │  │  │           │   │ │   │
   └─────┘          └─────┘          └──┴──┘           └───┘ └───┘
                                      幾乎重疊           幾乎沒碰到
```

評分會從 IoU **0.4 掃到 0.75**，門檻越高代表要求越準。

### 這題特別的地方（三個陷阱）

> 🚨 **陷阱一：漏框跟多框，罰得一樣重。**
> 一般的精確度只算「我畫的框對不對」，但這題的公式是：
>
> ```
>              答對的框數
>    ──────────────────────────────
>    答對 + 畫錯的 + 漏掉的
> ```
>
> 分母多了「漏掉的」。所以**不能只衝準確也不能只衝全面**，要抓平衡。

> 🚨 **陷阱二：本來沒肺炎的片子，你亂畫一個框 → 這張直接 0 分。**
> 而且測試集裡大概 **2/3 都是沒肺炎的片子**。
>
> 👉 這代表什麼？**「該不該出框」的決定，比「框畫得準不準」更重要。**
> 我們之後要調一個「信心門檻」—— 模型信心低於多少就不輸出框。
> 這一個參數的影響，往往比換模型還大。**這是我們簡報可以講的亮點。**

> 🚨 **陷阱三：IoU 最高只要求 0.75。**
> 比一般物件偵測（要求到 0.95）寬鬆很多。
> 代表「框得大概對」就有分，不用追求完美貼合。力氣要花對地方。

### 分數大概長怎樣

當年**第一名也只有 0.25**。

所以如果我們做出 0.15，那是很正常也很合理的成績。
**不要被低分數嚇到，也不要以為自己做錯了。**
這題本身就很難（連醫師都會看錯）。

## 5. 實作流程 —— 五個步驟

這是簡報第 4 頁的主體。整個流程長這樣：

```
 ①拿資料      ②轉格式       ③轉標註        ④訓練模型      ⑤調門檻+交卷
┌────────┐  ┌────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
│ Kaggle │─►│ DICOM  │─►│ CSV 座標 │─►│  YOLOv8  │─►│ 掃描信心 │
│ 下載   │  │  ↓     │  │   ↓      │  │   訓練   │  │ 門檻找最 │
│ 3.7 GB │  │ PNG    │  │ YOLO格式 │  │          │  │ 佳值→交 │
└────────┘  └────────┘  └──────────┘  └──────────┘  └──────────┘
```

### ① 拿資料

去 Kaggle 下載，3.7 GB。要先在競賽頁按「I Understand and Accept」接受規則。

### ② 把 DICOM 轉成 PNG

**為什麼要轉？** 因為幾乎所有現成的深度學習工具都吃 PNG / JPG，不吃 DICOM。
順便把 1024×1024 縮成 640×640 —— 不縮的話顯卡記憶體會爆，而且訓練超慢。

### ③ 把標註轉成 YOLO 格式

**為什麼要轉？** 因為格式不一樣：

| | CSV 給我們的 | YOLO 要的 |
|---|---|---|
| 位置 | 左上角 x, y | **中心點** cx, cy |
| 單位 | 像素（0~1024） | **比例**（0~1） |

所以要做個換算。沒肺炎的片子也要產生一個**空白的標註檔**，
這樣模型才知道「這張是反例，什麼都不要框」—— 這步漏掉模型會學歪。

### ④ 訓練模型

用 **YOLOv8**。一行指令就開始訓練，它會自己做資料增強、自己算分數。

**為什麼選 YOLO 而不是自己刻？**
- 我們的重點是「把題目做對」，不是「重造輪子」
- 一個晚上就能跑出第一個結果，簡報第 4 頁馬上有數字
- 之後想換 Faster R-CNN 做對照實驗也很容易，前面的資料處理可以共用

### ⑤ 調門檻 + 產生答案檔

訓練完的模型會輸出一堆框和信心值。我們要決定：**信心低於多少就丟掉？**

太低 → 一堆沒肺炎的片子被亂框 → 陷阱二，大扣分
太高 → 真的有肺炎的漏掉 → 陷阱一，也扣分

所以要在驗證集上**掃一遍**，畫出「門檻 vs 分數」的曲線，找最高點。
這張曲線圖放進簡報會很好看。

最後把框的座標**乘回 1024 尺度**（因為我們是用 640 訓練的），寫成 CSV 交上去。

## 8. 組員大概會問的問題

**Q：我不太會深度學習，可以做嗎？**
可以。P1、P2、P5 完全不需要碰模型，只要看得懂資料和規則。
P3 只需要跑一行指令出圖，然後解讀圖。真正要動模型的只有 P4。

**Q：我們要自己刻 YOLO 嗎？**
不用。用現成的 `ultralytics` 套件。我們的價值在「**針對這題的分析和調校**」——
特別是門檻調校那段，那才是這題的真功夫。

**Q：我電腦沒有獨顯 / 空間不夠怎麼辦？**
用 **Kaggle Notebook**，每週有 30 小時免費 GPU，而且**資料已經掛在上面不用下載**。
或者 Google Colab 也行。

**Q：分數很低是不是我們做錯了？**
不是。第一名 0.25。我們做到 0.15 就很好了。
報告的重點是**分析和方法論**，不是分數高低。

**Q：為什麼不用更新的 YOLO 版本？**
可以用，`ultralytics` 套件裡新舊版本都有，換個模型名稱就好。
但先用穩的把流程跑通，**有結果比有最新技術重要**。

**Q：期末最後要交什麼？**
那是後面幾週的事。Week 12 就只要這 5 頁。一次處理一件事。
